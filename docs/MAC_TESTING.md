# First Mac and iPhone check

Use Xcode 27 and an iOS 27 iPhone simulator. Run `bash scripts/check-ios.sh`. For physical widgets and Shortcuts, configure both targets with your team and the same App Group in `Config/Signing.xcconfig` / Signing & Capabilities.

1. Finish onboarding; create a yes/no habit and verify first tap completes, second clears, and relaunch preserves it.
2. Create a count habit with target 3; log 2, then 3, then 5. Check partial/full tiles, one qualifying day and saved over-goal total.
3. Create a measure habit with target 0.3; use Shortcuts to add 0.1 then 0.2. Check the precise total.
4. Backfill yesterday, and a day before a new habit's start (the start moves back); add a note to a zero-progress day. Clear progress and confirm the note survives. Disable/re-enable notes and confirm they remain.
5. Change today's goal and check yesterday's result is unchanged. Convert build/quit and verify old scoring, today's cleared amount and retained note.
6. Exercise weekly 3 and monthly 20 schedules; compare streaks to the installed reference, including a short month and unfinished current period.
7. Exercise quit yes/no and numeric threshold 3; 2.999 is clean and 3 is a slip. Archive across a day boundary, restore, and verify archived dates are not inferred clean.
8. Switch all three overviews, week start and recent-day settings. Reorder and filter categories. Delete a category without deleting habits.
9. Review yearly/monthly/hourly statistics. Create/share PNGs in both themes and all four year-review formats. Try many habits.
10. Create multiple reminders, deny/grant notifications, complete or slip today, and inspect pending notifications and tomorrow's coverage. Check DST and travel; reopen after a week.
11. Add all widget families; choose a habit, tap rapidly, reopen app, remove/archive the configured habit, and cross midnight. Verify totals converge and fallbacks are clear. Add each dashboard design in each size; tap Quick Check icons and a Routine widget's Complete All, and choose habits, a routine and a theme in Edit Widget.
12. Run all seven Shortcuts, including optional past date, note append, repeated complete above target, clear with note, archived habit and rejected future day.
13. Export/import valid data. Cancel both pickers. Reject corrupt, future-date and unsupported-version files. Restore a daily backup. The pre-restore file should be recoverable.
14. Explore: open each page. Create a routine, Complete All, and check counts fill to their target while quit habits stay unchanged. Start a countdown and a stopwatch; lock the phone, check the Live Activity and Dynamic Island, finish from the Lock Screen and confirm the minutes are logged to the start day. Turn on streak freezes, freeze a missed daily day, and check the streak and the snowflake. Add the Lock Screen widgets, the Today Ring in StandBy, and the Log Habit, Complete Routine and Habit Timer controls (also assign one to the Action button).
15. Compare reference and app screenshots on the same device width (393-point screenshots: an iPhone 15 Pro simulator). For the owner's HabitKit screenshots, launch with `SIMCTL_CHILD_BUDDY_VISUAL_SCREEN=cards|compact|detail|new-habit|settings`, `SIMCTL_CHILD_BUDDY_VISUAL_FIXTURE=reference`, `SIMCTL_CHILD_BUDDY_VISUAL_DATE=2026-10-03` and, for detail, `SIMCTL_CHILD_BUDDY_VISUAL_HABIT=1`; convert Display P3 captures to sRGB before sampling colors. Test small phone/landscape, large text, VoiceOver, light/dark, long titles and locale decimal input.

The 35 reference acceptance checks are also retained under `research/habitkit/06_ios_plan/acceptance_checks.txt`. Entries describing Pro transactions remain outside the implemented commerce scope.

## Automated native captures

After selecting an installed iPhone simulator, run `xcodebuild -project HabitBuddy.xcodeproj -scheme HabitBuddy -destination "platform=iOS Simulator,name=iPhone 16" -derivedDataPath DerivedData -resultBundlePath VisualAudit.xcresult CODE_SIGNING_ALLOWED=NO test`. Substitute your simulator name if necessary. The shared scheme includes `HabitBuddyUITests`; it captures 29 principal dark screens (including Streaks, List, Dashboard, the Today Ring, the Explore pages, Year History and Year Calendar), icon selection, six light screens, the timer's Live Activity on the Home Screen and the native share sheet. `testDashboardWidgetCaptures` pages through the default dashboard, every design and size (`BUDDY_VISUAL_SCREEN=widgets`, both themes) and the widget editor (`widget-config`). It checks that a dashboard check logs today, that an added widget appears, that a configured quick check shows its chosen habits, logs from an icon and duplicates, that a dashboard widget held and moved onto another takes its place and keeps it after a relaunch, that a routine widget's Complete All finishes the routine, that Complete All finishes a routine, and that a timer logs elapsed minutes when finished in the app or from its Live Activity's Finish button (pulled down in Notification Center), using only synthetic fixture data. Test attachments are in the result bundle.

`testHomeScreenWidgetGallery` is opt-in because it changes the Home Screen: on a simulator kept for it, build signed to run locally (omit `CODE_SIGNING_ALLOWED=NO`, so the App Group works) and run it with `TEST_RUNNER_BUDDY_HOME_WIDGETS=1`. It loads the sample habits into the real store, pages through Habit Buddy's widget gallery (25 designs and sizes), adds This Year, Goal Ring, Routine and Quick Check to the Home Screen, then taps the Routine widget's Complete All and a Quick Check icon there.
